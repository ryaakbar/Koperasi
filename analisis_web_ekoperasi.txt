======================================================
   ANALISIS APLIKASI WEB E-KOPERASI SEKOLAH
======================================================


1. FITUR UTAMA (5 FITUR)
------------------------------------------------------

No | Fitur                                      | Deskripsi
---|--------------------------------------------|--------------------------------------------------
1  | Login & Autentikasi                        | Sistem login dengan username dan password untuk
   |                                            | mengakses halaman utama. Terdapat proteksi routing
   |                                            | (redirect ke login.html jika belum login).
   |                                            |
2  | Katalog Produk dengan Pencarian & Filter   | Menampilkan daftar produk koperasi (seragam,
   | Kategori                                   | pramuka, atribut) dalam grid. Pengguna bisa
   |                                            | mencari produk berdasarkan nama dan memfilter
   |                                            | berdasarkan kategori (Semua, Seragam, Pramuka,
   |                                            | Atribut).
   |                                            |
3  | Keranjang Belanja (Cart) dengan Pilihan    | Pengguna dapat memilih ukuran produk (S, M, L,
   | Ukuran                                     | XL), menambah produk ke keranjang, mengatur
   |                                            | jumlah (qty), melihat rincian di sidebar
   |                                            | keranjang, dan menghapus item dari keranjang.
   |                                            |
4  | Checkout & Pembayaran via WhatsApp         | Proses pembayaran yang menghasilkan nomor invoice
   |                                            | otomatis, menampilkan rincian pesanan (termasuk
   |                                            | ukuran) dan total tagihan, lalu mengirim
   |                                            | konfirmasi pembayaran ke WhatsApp koperasi sekolah.
   |                                            |
5  | Riwayat Pembelian                          | Menyimpan histori semua transaksi yang telah
   |                                            | dilakukan selama sesi, lengkap dengan nomor
   |                                            | invoice, tanggal, daftar item beserta ukuran,
   |                                            | dan total pembayaran.


======================================================
2. PENGGUNAAN APLIKASI (2 CONTOH)
======================================================

Penggunaan 1: Siswa Membeli Seragam Sekolah
------------------------------------------------------
1. Siswa membuka web dan login dengan username "arya" / password "123"
2. Di halaman utama, siswa melihat katalog produk koperasi
3. Siswa mencari "Baju Seragam" melalui kolom pencarian atau memilih
   filter kategori "Seragam"
4. Siswa klik tombol "Tambah", memilih ukuran (S/M/L/XL), mengatur
   jumlah di bottom sheet, lalu klik "Masukkan Keranjang" atau
   "Beli Sekarang"
5. Siswa membuka keranjang, mengecek pesanan (termasuk ukuran yang
   dipilih), lalu klik "Lanjut Pembayaran"
6. Siswa mengisi kelas, melihat rincian & total tagihan, lalu klik
   "Konfirmasi & Bayar"
7. Otomatis terbuka WhatsApp dengan pesan rincian pesanan (termasuk
   ukuran) ke nomor koperasi sekolah

Penggunaan 2: Siswa Mengecek Riwayat Pembelian
------------------------------------------------------
1. Siswa login ke aplikasi E-Koperasi
2. Setelah sebelumnya melakukan beberapa transaksi, siswa klik menu
   "Riwayat" di navigasi
3. Modal riwayat pembelian muncul menampilkan semua transaksi sebelumnya
4. Siswa bisa melihat nomor invoice, tanggal, item yang dibeli beserta
   ukurannya, dan total pembayaran dari setiap transaksi

======================================================
CATATAN
======================================================
- Semua data produk dan transaksi dikelola secara client-side menggunakan
  JavaScript (tanpa backend/database).
- Sesi login disimpan di LocalStorage browser.
- Riwayat pembelian hanya tersimpan selama sesi halaman aktif (hilang
  saat refresh).
- Ukuran yang tersedia: S, M, L, XL. Default ukuran saat membuka
  bottom sheet adalah M.
- Produk yang sama dengan ukuran berbeda akan disimpan sebagai item
  terpisah di keranjang.
